## Responsive Landing Page

A modern and responsive landing page built using HTML, CSS, and JavaScript.
This project features an interactive navigation menu with smooth scrolling, hover effects, active section highlighting, and dynamic background color changes for different sections.

## Features
Responsive design
Fixed navigation bar
Smooth scrolling effect
Interactive hover animations
Active menu highlighting
Multiple sections (Home, About, Services, Contact)
Dynamic section color changes
Scroll-based navbar styling
## Technologies Used
HTML5
CSS3
JavaScript

│

## How to Run
Download or clone the project
Open index.html in your browser
## Output

Interactive responsive landing page with navigation effects and section-based color transitions.
